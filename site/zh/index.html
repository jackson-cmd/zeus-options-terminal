快速开始

需要 Python 3.10 或更新。第一次启动会自己建虚拟环境、装好依赖。

git clone https://github.com/jackson-cmd/zeus-options-terminal
cd zeus-options-terminal
./start.sh          # macOS / Linux（Windows 双击 start.bat）

也可以不下载代码：pipx install zeus-options-terminal，然后运行 zeus。

  1. 浏览器会自己打开 http://localhost:8765。
  2. 点 载入示例组合，用按当天报价生成的示例组合四处看看。
  3. 然后在 ⚙ 设置里连 tastytrade、Alpaca 或 Public，或者上传你的交易 CSV。

常见问题

宙斯期权终端免费吗？

个人、非商业使用免费（PolyForm Noncommercial 许可证）。它跑在你自己的电脑上，不用订阅，也不用注册账号。

一定要有 tastytrade 账户吗？

不用。可以连 tastytrade、Alpaca（免费，自带模拟盘）或 Public，也可以上传任何券商导出的交易 CSV。没有券商行情时用免费源：Cboe 期权（约延迟 15 分钟）和 Yahoo Finance 股票。还有一个示例组合，可以先把每个页面试一遍。

它会帮我下单吗？

不会。它只从券商读取持仓和行情。模拟盘里的交易只是练手，不会发给任何券商。

我的数据存在哪里？

只存在你自己的电脑上（~/.zeus-terminal）。密钥、交易和设置都不会离开这台电脑，只在请求你自己接入的券商或服务时发给对方。没有任何遥测。

能在哪些系统上用？

macOS、Linux 和 Windows，需要 Python 3.10 或更新。桌面通知只支持 macOS；邮件提醒支持 macOS 和 Linux。

有中文界面吗？

有。界面随时在中文、双语和英文之间切换，新闻标题也可以中英对照显示。
