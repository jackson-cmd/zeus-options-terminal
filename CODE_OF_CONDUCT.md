# Code of conduct · 行为准则

[English](#english) · [中文](#中文)

---

## English

ZEUS follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short:

- Be kind and patient. People come here with every level of experience, writing in English or Chinese.
- Talk about the code and the idea, not the person.
- No harassment, insults, sexual content, or posting anyone's private information.
- No trade calls, paid signal groups, referral links or other promotion. Nothing here is investment advice, and nobody should push others into a trade.

This holds in issues, pull requests, discussions and anywhere else you speak for the project.

### When something goes wrong

Use GitHub's **Report content** on the comment, which goes to GitHub's staff, or tell the maintainer privately through **Security → Report a vulnerability** ([direct link](https://github.com/jackson-cmd/zeus-options-terminal/security/advisories/new)) with a title that starts with "Conduct:". Only the maintainer reads it. The maintainer may edit or remove comments, lock threads and block accounts that keep breaking these rules.

## 中文

ZEUS 遵守 [Contributor Covenant 2.1](https://www.contributor-covenant.org/zh-cn/version/2/1/code_of_conduct/)（贡献者公约）。简单说：

- 友善、耐心。来这里的人什么水平都有，用英文或中文都行。
- 讨论代码和想法，不针对人。
- 不骚扰、不辱骂、不发色情内容、不公开别人的隐私。
- 不喊单、不拉付费群、不发邀请链接和广告。这里的内容都不是投资建议，也别劝别人做哪笔交易。

在 Issue、PR、Discussions 以及任何代表本项目说话的地方都适用。

### 出了问题怎么办

在那条评论上用 GitHub 的 **Report content**（交给 GitHub 的工作人员处理），或者通过 **Security → Report a vulnerability**（[直达链接](https://github.com/jackson-cmd/zeus-options-terminal/security/advisories/new)）私下告诉维护者，标题以「Conduct:」开头，只有维护者能看到。维护者可以编辑或删除评论、锁定讨论，屡次违反的账号会被拉黑。
