# ZEUS Terminal 功能清单

[English → FEATURES.md](FEATURES.md) · [使用说明](USER_GUIDE_zh.md) · [回到 README](../README_zh.md)

ZEUS 的功能远不止 README 截图里那些。顶栏有 7 个页面，后台有 30 来个自动运行的任务，API 接口超过 200 个。这一页把现在能从界面里用到的功能全部列出来。欢迎提 PR，以后也可能继续加新功能（见[参与贡献](../CONTRIBUTING.md)）。

**每项功能需要什么：**

| 标记 | 含义 |
|---|---|
| 免费 | 免费（手动）模式加公开数据就能用 |
| tastytrade | 需要连上 tastytrade 账户 |
| Benzinga | 需要 Benzinga Pro 登录（cookie） |
| Benzinga API | 需要 Benzinga 数据 API key |
| AI | 需要配一个 AI（Claude Code CLI、Anthropic API 或任何 OpenAI 兼容接口） |
| macOS | 桌面通知只支持 macOS |
